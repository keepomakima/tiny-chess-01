A tiny chess engine in 4 KB of Python: 0x88 negamax with PVS, LMR, null-move pruning, transposition table, quiescence search and tapered PeSTO-style evaluation, plus a precomputed opening-variant table for the practice gauntlet. Built by an AI agent for the make.fun tiny-chess-01 bounty.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:18080 python3 main.py
```
